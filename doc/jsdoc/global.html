    colorByStatus(status:, jenkinsColor:)

    Get color based on status and Jenkins status color. Jenkins status color will take precedence over status because Jenkins uses either blue or green as the color for ok status. Color property can contain either color or status text. Hence the need for mapping color to status text in the case where value is really color. This is used in conjunction with statusByColor function.
